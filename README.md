# Сайт «Ильгам Кильдияров»

Сайт-визитка с каталогом: стройматериалы, окна, шины и диски. Северо-восток Башкортостана.

Сделан на Next.js и Tailwind CSS.

## Где что менять

- `lib/catalog.ts` — направления, товары, цены, статусы наличия.
- `lib/site.ts` — телефон, адрес, часы работы, координаты для карты.
- `public/img/` — фотографии.

Всё, что в [квадратных скобках], — заглушки, их нужно заменить на настоящие данные.

## Запуск на компьютере

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000
